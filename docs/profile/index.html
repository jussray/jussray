How I build

The operating method is designed to keep ambition high without letting evidence, authority, or rollback disappear under it.

Preserve intent. Start with the actual outcome before touching the system.
Find the real blocker. One cause before ten symptoms.
Prefer reversible moves. Small, bounded changes compound better than dramatic rewrites.
Separate evidence planes. Source, CI, deployment, runtime, browser, device, and outcome are not interchangeable.
Keep authority scoped. Better reasoning does not grant broader permission.
Verify the real path. For UI work, browser evidence matters more than a green-looking diff.

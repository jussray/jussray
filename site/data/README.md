# Juss & Co public data contracts

These files are public presentation and discovery surfaces, not operational registries or authorization sources.

- `discovery.json`: selected public product purposes, source links and public status boundaries.
- `worlds.json`: existing public brand identities, display details and public contact destinations. Evidence fields remain empty until an explicitly approved public receipt contract is available.
- `systems.json`: independent public system identities and declared public destinations; no internal carrier or provider records.
- `connectors.json`: public provider names only; no internal mappings or implementation details.
- `portfolio.json`: non-authorizing public portfolio presentation, with an HTML snapshot for discovery and graceful fallback.

A declared source or destination does not establish current operation, integration or payment readiness. Internal inventory, operational receipts, private repository identities, builder identifiers, preview links and proprietary implementation details belong outside public distribution.

Keep existing brands and navigation intact. Public claims require scoped evidence. Run the existing discovery and site-proof tests before publication.
